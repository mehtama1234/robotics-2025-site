How a policy improves from experience

A robot that learns by trial and error stands or falls on four decisions: what to reward, when to explore, how to assign credit for a delayed reward, and how to know a new policy is actually better. Get any wrong and the agent games its reward, converges on a mediocre habit, learns nothing, or ships the worse policy. Each is a plain rule, run and measured on a small tabular-RL problem. Built in the demo-package style of the CV project: a tested, reusable core behind every stage.

1

Reward Design & Hacking

An RL agent optimises the reward you write, not the behaviour you meant. Add an intuitive bonus to speed it up — 'reward getting near the workbench' — and the agent finds the loophole: it farms the bonus forever and never does the task.

Shape a reward as a potential difference so you speed learning without changing what's optimal; any other bonus can be gamed.
beacon-bonus agent reaches goalno — it farms the bonus
potential-shaped agent reaches goalyes, in 12 steps (optimal)
goal reward vs farmable bonus/step1.0 vs 0.3

In a 7×7 reach-the-goal grid, an agent trained with a farmable beacon-proximity bonus (+0.3/step) never reaches the goal — it loops by the beacon collecting bonus. The same agent with a potential-based bonus reaches the goal by the optimal 12-step path.

2

Exploration vs Exploitation

An agent that always takes its current best action locks onto the first option that happened to look good and never discovers the better one sitting one try away. It converges — confidently — to a mediocre policy.

Explore, or you converge on the first option that looked good rather than the best one.
best-arm rate (final) — greedy36%
best-arm rate (final) — ε-greedy62%
total regret — greedy vs ε-greedy235 vs 166

On a 10-armed bandit over 2000 pulls, a purely greedy agent ends up pulling the best arm only 36% of the time; an ε-greedy agent (10% exploration) reaches 62% — and cuts total regret from 235 to 166.

3

Credit Assignment & Discounting

The reward for a robot task arrives at the very end — the object is placed, the room is reached. Which of the hundred earlier actions deserves the credit? An agent that only values the immediate reward sees zero everywhere and learns nothing.

Credit an action by its discounted future return; a myopic agent cannot learn a delayed reward.
discounted agent (γ=0.9) reaches goalyes, in 7 steps
myopic agent (γ=0) reaches goalno — stuck at the start
chain length (reward at the end)8 states

On an 8-state chain with reward only at the far end, a discounted agent (γ=0.9) propagates the value back and reaches the goal by the optimal 7-step path. A myopic agent (γ=0) sees zero reward everywhere but the last step and never leaves the start.

4

Policy Evaluation Under Noise

You have a new policy that beat the old one in a quick test, so you ship it. But robot episodes are noisy, and the quick test was a handful of runs — the 'win' may be pure luck, and you have just deployed the worse policy.

Evaluate across enough episodes to beat the noise; a single small-sample win is often luck.
picks the better policy — 3 episodes60%
picks the better policy — 200 episodes98%
true return gap (B over A)0.2

When policy B is truly better than A by just 0.2 in mean return (with unit-variance noise), a 3-episode eval crowns the better policy only 60% of the time — barely better than a coin flip. A 200-episode eval gets it right 98% of the time.
