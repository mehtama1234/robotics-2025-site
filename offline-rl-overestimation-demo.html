Offline RL and the overestimation trap

On a fixed dataset, a naive Q-learner hallucinates high values for actions it never saw — then the greedy policy walks straight into them. A conservative penalty fixes it.

home · the build lab · the method zoos · RL & imitation

Offline (batch) RL learns a policy from a fixed logged dataset with no new interaction — the setting when real trials are costly or unsafe. The catch: the Bellman backup takes a max over ALL actions, including out-of-distribution ones the dataset never tried, so their bootstrapped Q-values are never corrected by a real reward. Conservative Q-learning (CQL) adds a penalty that pushes those unsupported Q-values down, keeping the learned value honest.

we ran itWe built an 8-cell corridor MDP with a known optimal value and a LURE action the behavior policy never takes, so every (state, LURE) pair is out-of-distribution. Naive fitted-Q left the LURE inflated — mean value overestimation 1.164 (max 1.317) over true V* — so its greedy policy took the LURE in every interior state and earned a true return of -1.00 (straight into the trap). The conservative learner cut overestimation to 0.000, recovered the always-RIGHT optimal policy, and scored a true return of +0.836 — matching the optimal +0.836.
the failure it shows Bootstrapping a Bellman max over out-of-distribution actions manufactures value that the data can never refute; the greedy policy then exploits that hallucination and collapses when actually run.
