Measured-number drift

✓ PASS

The subtlest failure: a page might quote '22x speedup' while the experiment now produces '14x'. The drift check reads these measurements back out of the page prose and confirms each one still matches the raw result in the data. Numbers age; this ensures they don't age in the prose while the code moves on.

Reproduce it yourself

Nothing here is privileged. The same script that renders this page runs every check — clone the source and run it:

python3 scripts/build_scorecard.py   # recomputes all six checks, rewrites this page
node source-code/learning/<pkg>/tests/core.test.js   # any single tested core

When all six checks pass, the collection's central claim holds mechanically: everything you read here was really computed, every paper really exists, every number is current. When any check goes red, this scorecard is the first to tell you. Trust is binary.
