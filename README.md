# Robotics 2025 — ICRA + IROS analysis

Every paper from ICRA 2025 and IROS 2025, read and analyzed (problem · approach · contribution), mined for themes, and for key topics reviewed down to the real code — with a handful of the papers' methods actually run as live demos.

**Live site:** https://mehtama1234.github.io/robotics-2025-site/

- First-principles "big picture" synthesis per theme (sense · decide · move)
- Plain course spine: Robotics From First Principles (`course.html`)
- Code walkthroughs of cloned repos
- Live "we ran it" demos: SparseDrive (BEV driving), MCTrack (3D tracking), 3D Gaussian Splatting (garden fly-through), SeaSplat (underwater color restoration)

Static site — no build step.
